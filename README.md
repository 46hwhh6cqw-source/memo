# 🎨 アートメモ帳

メモ帳に特化したアプリに、関数電卓とデジタルアート機能を加えたオールインワンツールです。
**通信は一切せず**、データはすべて端末内(localStorage)に自動保存されます。

## 2つの使い方

### ① Android アプリとして使う(おすすめ)
`android/` フォルダが **Android Studio プロジェクト**です。Android Studio で `android`
フォルダを開き、実機をつないで ▶ Run するだけで、いつも通りアプリとしてインストールできます。
詳しい手順は [`android/README.md`](android/README.md) を参照してください。

### ② ブラウザで手早く試す
リポジトリ直下の `index.html` をブラウザで開くだけでも同じものが動きます(インストール不要)。
Android アプリの画面の中身も、この Web 版と同じファイルです。

## 機能

### 📝 メモ帳
- 複数メモの管理(一覧・検索・ピン留め)
- 入力内容の自動保存
- 作成日時 / 更新日時 / 文字数の表示
- メモを `.txt` でダウンロード
- 全メモの JSON バックアップ & 復元

### 🖌 デジタルアート
主要なペイントツールの定番機能を取り入れたお絵かき機能です。

- **ブラシ**: ペン / 鉛筆 / マーカー / エアブラシ / 消しゴム(サイズ・不透明度・手ぶれ補正)
- **筆圧対応**: ペンタブレット・スタイラスの筆圧で線の太さが変化
- **レイヤー**: 追加 / 複製 / 結合 / 並べ替え / 表示切替 / 不透明度 / ブレンドモード(乗算・スクリーン・オーバーレイ・加算)
- **カラー**: HSV カラーピッカー / HEX 入力 / スウォッチ / 最近使った色 / スポイト(Alt+クリックでも可)
- **塗りつぶし**(バケツツール)
- **アンドゥ / リドゥ**(Ctrl+Z / Ctrl+Y)
- **ズーム & パン**(マウスホイール / ピンチ操作 / 手のひらツール / Space+ドラッグ)
- **PNG 書き出し**(透過 / 白背景)
- **ギャラリー**: レイヤー構成ごと保存して後から再編集可能
- 作業中の絵は自動保存され、次回開いたときに復元されます

#### ショートカットキー
| キー | 機能 |
|---|---|
| B / P / M / A / E | ペン / 鉛筆 / マーカー / エアブラシ / 消しゴム |
| G / I / H | 塗りつぶし / スポイト / 手のひら |
| `[` / `]` | ブラシサイズ変更 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Space+ドラッグ | キャンバス移動 |

### 🔢 関数電卓
- 四則演算・括弧・べき乗(`^`)・百分率(`%`)
- 三角関数(sin / cos / tan と逆関数、DEG / RAD 切替)
- log / ln / √ / x² / π / e
- メモリ機能(MC / MR / M+ / M−)と Ans(直前の答え)
- 計算履歴(クリックで再利用、自動保存)
- キーボードから式を直接入力して Enter で計算可能
